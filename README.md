# Linux File Permissions & Access Control Lab

## 📌 Objective
To practice and understand Linux terminal commands for managing file and directory permissions (`chmod`, `chown`, `chgrp`) to ensure proper access control and system security.

---

## 🛠️ Tools & Technologies Used
* **Operating System:** Linux (Terminal / Command Line)
* **Key Commands:** `chmod`, `chown`, `ls -l`, `sudo`

---

## 📋 Steps & Implementation

1. **Checking File Permissions:**
   * Used `ls -l` command to list files and view their current read, write, and execute permissions for user, group, and others.

2. **Modifying Permissions (`chmod`):**
   * Applied numeric and symbolic modes (e.g., `chmod 755` or `chmod +x`) to restrict or grant access to specific users.

3. **Changing Ownership (`chown`):**
   * Assigned file ownership to specific users and groups to maintain strict access control policies.
